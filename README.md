# Página web de la iglesia

Sitio de la iglesia hecho con React, TypeScript y Vite. El proyecto se construye por etapas y también sirve para aprender React.

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

## Estructura

```
src/
  components/   Piezas reutilizables (Header, Footer, tarjetas...)
  pages/        Una página por ruta (Home, Nosotros, Eventos...)
  data/         Datos locales (horarios, versículos, eventos...)
  App.tsx       Componente raíz
  main.tsx      Punto de entrada
  index.css     Estilos globales
public/
  images/       Imágenes del sitio
```

Las explicaciones de cada etapa están en la carpeta `docs/`.
